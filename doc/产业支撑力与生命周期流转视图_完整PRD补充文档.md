### 1.3 功能详解

#### 1.3.1 支撑力健康度仪表盘

**功能描述**：在热力图上方展示3张核心分析卡，让用户3秒内知道"整体好不好、哪里最差、哪里最能提升"。

**卡片1：整体支撑评分**

**字段表格：**

| 字段 | 类型 | 说明 | 计算逻辑 |
|---|---|---|---|
| overall_score | Float | 整体支撑健康度评分（0-100） | `Σ(各产业实际支撑频次 / 理论基准频次) / 产业数 * 100` |
| score_level | Enum | 评分等级 | 见枚举值表 |
| trend | Float | 环比变化（%） | `(本月评分 - 上月评分) / 上月评分 * 100` |
| trend_direction | Enum | `up`/`down`/`flat` | 正数↑，负数↓，0→持平 |

**枚举值表格（score_level）：**

| 值 | 说明 | 颜色 | 阈值 |
|---|---|---|---|
| `excellent` | 优秀 | 绿色 `#52C41A` | ≥80分 |
| `good` | 良好 | 蓝色 `#1890FF` | 60-80分 |
| `warning` | 预警 | 橙色 `#FA8C16` | 40-60分 |
| `danger` | 危险 | 红色 `#F5222D` | <40分 |

**理论基准频次计算规则：**

```
理论基准频次 = 目标产业企业数 × 该产业平均服务需求系数 × 季度系数

其中：
- 平均服务需求系数：根据行业经验值设定
  - 金融服务：0.3次/企业/季度（每家企业每季度约需0.3次金融服务）
  - 贸易物流：0.8次/企业/季度
  - 科技服务：0.5次/企业/季度
  - 人力资源：0.4次/企业/季度
  - 法律服务：0.2次/企业/季度
  - 信息服务：0.6次/企业/季度
- 季度系数：当前季度相对于年均的波动系数（Q1=0.9, Q2=1.0, Q3=1.1, Q4=1.2）
```

**卡片展示内容：**

```
┌────────────────────────────────────────┐
│ 整体支撑评分                            │
│ ┌────────────────────────────────────┐ │
│ │           72分                      │ │
│ │         ▓▓▓▓▓▓▓░                   │ │  ← 环形进度条，72%填充
│ │                                    │ │
│ │  良好  ↑ 环比 +5%                 │ │  ← 等级标签+趋势
│ │                                    │ │
│ │  覆盖6类服务业 × 8类重点产业       │ │  ← 覆盖范围
│ │  48个单元格中：充足12 | 一般15      │ │  ← 分布统计
│ │           薄弱14 | 缺失7           │ │
│ └────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

**整体健康度评分：**

**字段表格：**

| 字段 | 类型 | 说明 | 计算逻辑 |
|---|---|---|---|
| overall_health_score | Float | 整体健康度评分（0-100） | 见下方公式 |
| structure_type | Enum | 结构类型 | 见枚举值表 |
| risk_warning | Text | 结构风险警告 | 自动生成 |
| recommendation | Text | 结构优化建议 | 自动生成 |

**健康度评分公式：**

```
overall_health_score = 100 - |未来偏差| * 2 - |新兴偏差| * 1.5 - |优势偏差| * 1

其中：
- 未来偏差 = 实际占比 - 15%（理想）
- 新兴偏差 = 实际占比 - 35%（理想）
- 优势偏差 = 实际占比 - 50%（理想）

注：偏差取绝对值，权重反映对产业生态的影响程度
  - 未来产业占比过高 = 培育资源分散，转化效率低（权重2）
  - 新兴产业占比偏差 = 增长动能不足或过热（权重1.5）
  - 优势传统占比偏低 = 税收就业根基不稳（权重1）
```

**枚举值表格（structure_type）：**

| 值 | 说明 | 条件 | 颜色 |
|---|---|---|---|
| `olive` | 橄榄型（健康） | 未来10-20%，新兴30-40%，优势40-55% | 绿色 |
| `pyramid` | 金字塔型（未来过多） | 未来>20%，优势<40% | 橙色 |
| `inverted_pyramid` | 倒金字塔型（传统过多） | 未来<10%，优势>60% | 橙色 |
| `dumbbell` | 哑铃型（两头大中间小） | 未来>20%且优势>55% | 红色 |
| `single_peak` | 单峰型（新兴独大） | 新兴>50% | 蓝色 |

| 结构类型 | 生成的risk_warning |

## 五、附录

### 5.1 术语表

| 术语 | 说明 |
|---|---|
| 支撑力健康度 | 现代服务业对重点产业的实际支撑能力相对于理论基准的得分 |
| 理论基准频次 | 根据产业规模、复杂度、发展阶段计算的预期服务需求 |
| 活跃率 | 实际发生交互的服务企业数 / 本区服务供给企业总数 |
| 外流金额 | 目标产业因本地服务缺失而从外地采购服务的金额估算 |
| 可激活企业 | 本区已有服务供给能力，但未与目标产业发生交互的企业 |
| 生命周期健康度 | 全区产业生命周期结构（未来:新兴:优势）相对于理想橄榄型结构的偏差评分 |
| 橄榄型结构 | 理想产业结构：未来15%、新兴35%、优势50% |
| 卡滞产业 | 处于某阶段超过预期时长，未能进入下一阶段的产业 |
| 成长驱动力 | 推动产业从低阶段向高阶段流转的主要力量：政策/市场/技术/资本 |
| 流转状态 | 产业企业从A阶段到B阶段的健康程度：健康/缓慢/卡滞/逆向 |
