## 一、产业全景看板

### 1.1 页面概述

| 项目 | 内容 |
|---|---|
| **页面名称** | 产业全景看板 |
| **路由路径** | `/industry/panorama` |
| **核心目标** | 通过三维属性矩阵筛选器（战略导向×生命周期×交叉使能），按用户定义维度动态浮现产业，以卡片矩阵展示产业存量+增量双指标，支撑决策者"一眼看清产业态势、快速定位问题产业" |
| **数据来源** | 产业链配置表（industry_chain）、企业工商/税务数据、使能技术标签表、在建项目数据、招商进度数据、供需缺口数据、风险预警数据 |
| **使用角色** | 区领导、发改局、招商局、工信局 |
| **页面类型** | 列表+概览页（非详情页） |

### 1.2 页面布局

从上到下分为 **5 个区域**：

- **区域1：三维产业治理筛选器**（高度：120px）— 战略导向、生命周期、交叉使能三个维度横向排列，支持交叉筛选
- **区域2：核心指标栏**（高度：120px）— 4张指标卡横向排列，展示全局态势数字
- **区域3：视图切换标签**（高度：48px）— 产业矩阵/产业支撑力/生命周期流转三个视图切换
- **区域4：产业矩阵卡片区**（自适应主区域）— 筛选结果以卡片矩阵展示，支持横向滚动或分页
- **区域5：底部快捷分析区**（高度：200px）— 三栏布局：供需缺口TOP5、供应链风险TOP5、支撑产业活跃度热力图

### 1.3 功能详解

#### 1.3.1 三维产业治理筛选器

**功能描述：** 用户通过战略导向、生命周期、交叉使能三个维度交叉筛选，动态浮现符合条件的产业。

**字段表格：**

| 字段 | 类型 | 说明 | 校验规则 |
|---|---|---|---|
| filter_strategic | Enum[] | 战略导向筛选值 | 可多选，默认["all"] |
| filter_lifecycle | Enum[] | 生命周期筛选值 | 可多选，默认["all"] |
| filter_enabling | Enum[] | 交叉使能筛选值 | 可多选，默认["all"] |
| result_count | Int | 筛选结果数量 | 实时计算，只读 |

**枚举值表格：**

| 维度 | 值 | 说明 | 计数颜色 |
|---|---|---|---|
| 战略导向 | `all` | 全部 | 灰色 |
| 战略导向 | `chain_master` | 链主产业 | 深蓝 `#096DD9` |
| 战略导向 | `core_pillar` | 核心支柱 | 蓝色 `#1890FF` |
| 战略导向 | `cultivating` | 培育中 | 橙色 `#FA8C16` |
| 生命周期 | `all` | 全部 | 灰色 |
| 生命周期 | `future` | 未来产业 | 紫色 `#722ED1` |
| 生命周期 | `emerging` | 新兴产业 | 蓝色 `#1890FF` |
| 生命周期 | `advantage_traditional` | 优势传统 | 绿色 `#52C41A` |
| 交叉使能 | `all` | 全部 | 灰色 |
| 交叉使能 | `ai` | +AI | 靛蓝 `#2F54EB` |
| 交叉使能 | `iot` | +物联网 | 绿色 `#389E0D` |
| 交叉使能 | `green_energy` | +绿色能源 | 青色 `#13C2C2` |
| 交叉使能 | `industrial_internet` | +工业互联网 | 玫红 `#EB2F96` |

**筛选逻辑规则：**

| 规则 | 说明 |
|---|---|
| 维度间关系 | **"与"关系**：三个维度的选中条件同时满足才展示 |
| 维度内关系 | **"或"关系**：同一维度内多选时，满足任一条件即展示 |
| 默认状态 | 三个维度均选中`all`，展示全部产业 |
| 计数更新 | 括号内数字实时联动，反映当前其他维度条件下的可选数量 |
| 空结果处理 | 筛选结果为空时，展示"无符合条件的产业"提示，并提供"重置筛选"按钮 |

**交互说明：**
- 点击选项：切换选中/未选中状态，选中为蓝色实心圆+蓝色文字，未选中为灰色空心圆+灰色文字
- 点击`[重置筛选]`：恢复全部维度为`all`，卡片区恢复展示全部产业
- 筛选变更：卡片区实时更新（300ms防抖），无页面刷新
- URL同步：筛选条件同步到URL Query参数，支持分享和浏览器前进/后退

#### 1.3.2 核心指标栏

**功能描述：** 展示当前筛选条件下的全局态势数字，让决策者3秒内看清"家底"。

**字段表格：**

| 指标卡 | 指标值 | 计算逻辑 | 颜色规则 | 趋势对比 |
|---|---|---|---|---|
| 战略产业总数 | Int | 当前筛选条件下的产业链数量 | 蓝色 `#1890FF` | — |
| 急需补链数 | Int | 有严重缺失环节（覆盖度<20%）的产业数 | 红色 `#F5222D`，≥1时带脉冲呼吸动画 | — |
| 平均完整度 | Float | 当前筛选产业完整度评分的算术平均 | 环形进度条，≥80%绿，60-80%蓝，<60%红 | 环比上月箭头+数值 |
| 数字化渗透率 | Float | 应用使能技术的企业数 / 总企业数 | 蓝色 `#1890FF` | 环比上月箭头+数值 |

**量化规则：**

| 指标 | 公式 | 阈值 |
|---|---|---|
| 急需补链判定 | `存在环节覆盖度<20%` | — |
| 平均完整度 | `Σ(score_i) / count` | 0-100 |
| 数字化渗透率 | `enabling_enterprise_count / total_enterprise_count` | 0-100% |
| 趋势对比 | `(本月值 - 上月值) / 上月值 * 100%` | 正数绿色↑，负数红色↓ |

**交互说明：**
- 指标卡hover：轻微上浮（translateY: -2px），阴影加深
- 点击"平均完整度"卡：下钻完整度趋势分析（弹窗或跳转）
- 点击"急需补链数"卡：自动筛选`生命周期=全部`+`战略导向=全部`，卡片区按完整度升序排列，缺失产业置顶

#### 1.3.3 视图切换标签

**功能描述：** 支持三种数据视图切换，满足不同决策场景。

**枚举值表格：**

| 视图 | 值 | 说明 | 默认状态 |
|---|---|---|---|
| 产业矩阵 | `matrix` | 产业卡片矩阵（默认视图） | 选中 |
| 产业支撑力 | `support` | 现代服务业与重点产业的交互热力图 | 未选中 |
| 生命周期流转 | `lifecycle` | 桑基图展示产业演进路径 | 未选中 |

**交互说明：**
- 点击标签：切换视图内容区，URL锚点变更（`#matrix`/`#support`/`#lifecycle`）
- 视图状态：本地缓存（localStorage），刷新后恢复上次选择
- 未实现视图：点击后展示"功能开发中"占位提示（如当前仅实现`matrix`）

**排序规则：**

| 优先级 | 排序维度 | 规则 | 说明 |
|---|---|---|---|
| 1 | 急需补链 | 有严重缺失环节的产业置顶 | 让问题产业先被看到 |
| 2 | 完整度 | 升序排列（低的在前） | 完整度越低越需要关注 |
| 3 | 企业规模 | 按营收降序 | 同完整度下，大产业优先 |
| 4 | 战略优先级 | 链主产业>核心支柱>培育中 | 同规模下，战略地位高的优先 |

- 点击卡片任意区域（除按钮外）：**跳转**至产业链结构图谱页 `/industry/chain-graph/:chainId`
- 点击`[查看详情]`：右侧滑出抽屉，展示产业详细数据（不跳转页面）
- 点击`[查看产业链图谱]`：直接跳转图谱页
- 卡片hover：阴影加深（`0 4px 16px rgba(0,0,0,0.12)`），边框变粗至2px，"查看详情"按钮显现
- 卡片加载：筛选结果变更时，卡片带淡入动画（opacity 0→1，duration 300ms）

#### 1.3.5 底部快捷分析区

**功能描述：** 无需跳转页面，直接展示当前筛选条件下的关键问题TOP5和支撑产业活跃度。

**三栏布局：**

**字段表格（中栏-供应链风险TOP5）：**

| 字段 | 类型 | 说明 | 颜色规则 |
|---|---|---|---|
| risk_level | Enum | `紧急`/`重要`/`关注` | 红/橙/黄 |

| affected_count | Int | 影响企业数 | — |

**字段表格（右栏-支撑产业活跃度热力图）：**

| 字段 | 类型 | 说明 | 计算逻辑 |
|---|---|---|---|

**交互说明：**
- 左栏点击缺口项：跳转供需缺口分析页 `/supply-demand/gap?category=xxx`
- 中栏点击风险项：跳转风险预警页 `/decision-support/risk-warning?enterprise=xxx`
- 右栏点击热力图单元格：跳转产业支撑力视图 `/industry/panorama#support`，并高亮对应交互关系
- 三栏数据均随顶部筛选器联动更新（筛选特定产业时，只展示该产业相关的缺口/风险/交互）

### 1.5 交互流程

```
用户进入产业全景看板
    │
    ▼
系统加载默认状态：全部维度=all，展示全部产业卡片
    │
    ▼
用户调整筛选条件（如：战略导向=链主产业，生命周期=新兴产业）
    │
    ├── 触发筛选器变更事件
    ├── 300ms防抖后发送API请求
    ├── 核心指标栏实时更新
    ├── 卡片区淡入更新（按排序规则重新排列）
    └── 底部快捷分析区同步更新
    │
    ▼
用户点击某张产业卡片
    │
    ├── 路由跳转至 /industry/chain-graph/:chainId
    └── 携带 chainId 参数
    │
    ▼
用户点击"查看详情"按钮
    │
    └── 右侧滑出抽屉（不跳转，展示产业详细数据）
    │
    ▼
用户点击底部快捷分析区某一项
    │
    └── 跳转对应详情页面（供需缺口/风险预警/支撑力视图）
```

#### 2.3.3 产业链拓扑图谱（主区域）

**功能描述：** 以可视化网络图展示产业链结构，节点为环节，连线为流向关系。

**组件化设计：**

| 组件 | 类型 | 说明 | 配置参数 |
|---|---|---|---|
| `ChainTopology` | 网络图 | 产业链拓扑可视化 | `chainId`, `layoutType`, `zoomLevel` |
| `TopoNode` | 节点 | 环节节点 | `nodeId`, `name`, `count`, `status`, `enablingTech` |
| `TopoEdge` | 连线 | 环节流向 | `source`, `target`, `type`, `verified` |

**量化规则：**

| 规则项 | 计算逻辑 |
|---|---|
| 节点宽度 | 固定180px |
| 节点高度 | 自适应（基础60px + 使能标签行高） |
| 节点圆角 | 8px |
| 节点颜色 | 状态决定：优势`linear-gradient(135deg, #52C41A, #B7EB8F)`；一般`linear-gradient(135deg, #1890FF, #91D5FF)`；缺失`linear-gradient(135deg, #F5222D, #FFA39E)` + `box-shadow: 0 0 12px rgba(245,34,45,0.3)` |
| 节点边框 | 无（渐变背景已区分），hover时加2px白色边框 |
| 连线类型 | 实线=已验证供应关系（有交易发票记录）；虚线=推断关系（产品匹配但无交易记录） |
| 连线颜色 | 默认`#8C8C8C`，hover时变为`#1890FF` |
| 连线粗细 | 2px（默认），hover时3px |
| 箭头大小 | 8px，指向流向方向 |
| 布局类型 | 默认层次布局（Hierarchical）：上游左、中游中、下游右；可选力导向布局（Force） |

**节点内容结构：**

```
┌─────────────────┐
│  芯片设计        │  ← 环节名称，14px，font-weight: 600，白色文字
│  ─────────────── │  ← 分隔线，rgba(255,255,255,0.3)
│  ✓ 28家         │  ← 状态图标+企业数，12px，白色文字
│  [+AI] [+物联网] │  ← 使能标签，10px，白色底+深色文字，小圆角
└─────────────────┘
```

**布局算法（层次布局）：**

| 层级 | X轴位置 | 列数 | 对齐方式 |
|---|---|---|---|
| 上游 | 左侧（画布宽度的20%处） | 1-2列 | 垂直居中分布 |
| 中游 | 中间（画布宽度的50%处） | 1-2列 | 垂直居中分布 |
| 下游 | 右侧（画布宽度的80%处） | 1-2列 | 垂直居中分布 |
| 间距 | 层间水平间距≥200px，节点垂直间距≥80px | — | — |

**交互说明：**
- 画布支持：
  - 鼠标滚轮缩放（0.5x-3x）
  - 画布拖拽（平移）
  - 节点拖拽（调整位置，不保存）
- 节点悬停：
  - Tooltip显示：环节名称、企业数、覆盖度、缺失状态、使能技术列表、最近交易时间
  - 节点边框加粗至3px白色
  - 关联连线高亮（颜色变为`#1890FF`，粗细3px）
- 节点单击：
  - 右侧滑出`DetailDrawer`，展示该环节企业列表
  - 左侧导航树自动滚动并高亮对应行
- 节点双击：
  - 跳转企业关系网络图 `/enterprise/network?nodeId=xxx`
- 使能标签悬停：
  - Tooltip显示：该环节应用此技术的企业数、企业名称列表（前5家）
- 空白处双击：
  - 重置画布视角（居中+缩放至1x）

| 产业链基础信息 | ✓（列表展示） | ✓（顶部信息） | 名称、分类、战略标签、周期标签、完整度 |
| 完整度评分 | ✓（卡片展示） | ✓（顶部展示） | 系统计算，实时同步 |
| 企业数 | ✓（卡片展示） | ✓（节点展示） | 企业环节关联表统计 |
| 使能技术标签 | ✓（卡片展示） | ✓（节点展示） | 产业链级聚合 vs 环节级聚合 |
| 存量/增量指标 | ✓（卡片展示） | ✗ | 仅看板需要 |
| 环节结构 | ✗ | ✓（核心展示） | 产业链环节表，树形结构 |
| 环节企业列表 | ✗ | ✓（抽屉展示） | 企业环节关联表 |
| 供需关系（连线） | ✗ | ✓（图谱展示） | 企业关系表，用于渲染连线 |
| 使能技术分布 | ✗ | ✓（抽屉图表） | 环节级聚合 |
| 缺口/风险数据 | ✓（底部展示） | ✗（抽屉内展示） | 看板展示TOP5，图谱展示环节级明细 |

### 3.2 核心数据流

```
产业全景看板
    │
    ├── 用户调整筛选条件
    │   ├── 查询产业链表（带三维筛选条件）
    │   ├── 聚合企业数、完整度、存量/增量指标
    │   ├── 聚合使能技术标签
    │   └── 返回产业卡片列表
    │
    └── 用户点击某张产业卡片
        │
        └── 携带 chainId 跳转
            │
            ▼
产业链结构图谱
    │
    ├── 查询产业链基础信息（顶部信息栏）
    ├── 查询产业链环节树（左侧导航树）
    ├── 查询企业环节关联（节点企业数）
    ├── 查询供需关系（连线数据：实线/虚线）
    ├── 查询使能技术标签（节点标签）
    └── 渲染拓扑图谱
    │
    └── 用户点击节点
        │
        ├── 查询环节企业列表（抽屉企业表格）
        ├── 查询环节使能技术分布（抽屉饼图）
        ├── 查询环节供需缺口（抽屉缺口表格）
        └── 滑出抽屉展示
```

### 3.3 状态同步

| 状态 | 同步方向 | 机制 | 说明 |
|---|---|---|---|
| 筛选条件 | 看板→图谱 | URL Query参数 | 从图谱返回看板时恢复筛选 |
| 选中产业 | 看板→图谱 | URL Path参数 | `chainId` |
| 选中环节 | 图谱内部 | 组件状态 | 抽屉内展示，不跨页 |
| 缩放/布局 | 图谱内部 | localStorage | 刷新后恢复 |

### 4.1 术语表

| 术语 | 说明 |
|---|---|
| 战略导向 | 产业在区域战略中的定位：链主产业、核心支柱、培育中 |
| 生命周期 | 产业所处发展阶段：未来产业、新兴产业、优势传统 |
| 交叉使能 | 产业应用的横向使能技术：AI、物联网、绿色能源、工业互联网 |
| 存量指标 | 产业当前的经济贡献：税收、就业、营收 |
| 增量指标 | 产业的动态增长：在建项目、招商落地、增速 |
| 完整度评分 | 产业链各环节覆盖度的加权评分（0-100） |
| 环节覆盖度 | 实际企业数 / 参考基准企业数 |
| 已验证关系 | 有税务发票记录的企业间交易关系 |
| 推断关系 | 基于产品匹配但无交易记录的企业间潜在关系 |
| 层次布局 | 图谱布局算法：上游左、中游中、下游右 |
| 力导向布局 | 图谱布局算法：基于物理模拟的自动分布 |
