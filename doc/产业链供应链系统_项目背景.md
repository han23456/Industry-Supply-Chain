# 产业链/供应链图谱系统 — 项目背景

---

## 一、原始需求

> **产业链、供应链分析。基于产业链梳理、企业产品信息、业务关联数据，构建可视化产业链、供应链图谱，清晰展示企业间供需对接、上下游配套关系，实现产业链、供应链企业关联关系直观呈现。**

这是区政府的要求。

---

## 二、需求解读

从区政府的表述来看，这是一个**产业经济治理视角**的系统，核心目标是**让政府"看清"辖区内企业的产业链位置和关联关系**，从而服务于招商引资、产业补链强链、企业供需对接等政务决策。

---

## 三、区政府到底想要什么？

这段描述，本质上是**政府产业治理视角的"产业大脑"系统**。区政府想要的不是一个简单的数据展示平台，而是一个**能回答以下问题的决策工具**：

| 政府关心的问题 | 系统需要回答 |
|---|---|
| 我区有哪些产业链？完整度如何？ | 产业链全景图谱 |
| 哪些环节有断链/缺链风险？ | 产业链短板识别 |
| 企业之间谁供谁、谁需谁？ | 供需对接关系 |
| 招商引资该补哪一环？ | 强链补链建议 |
| 重点企业上下游依赖谁？ | 供应链风险预警 |

**核心目的：从"凭经验管产业"变成"用数据管产业"。**

---

## 四、系统的核心功能模块

```
┌─────────────────────────────────────────────────────────┐
│                    产业链/供应链图谱系统                   │
├─────────────────────────────────────────────────────────┤
│  ① 产业全景图谱层                                        │
│     • 本区重点产业链梳理（如：半导体、新能源、生物医药等）   │
│     • 产业链上中下游结构可视化（节点=企业/环节，连线=关系）   │
│     • 产业链完整度评分（哪些环节强、哪些环节缺失）            │
│                                                          │
│  ② 企业画像与关联层                                       │
│     • 企业基础信息（工商、产品、资质、专利等）               │
│     • 企业产品/服务目录（我能提供什么）                     │
│     • 企业需求目录（我需要什么）                            │
│     • 企业间供需关系图谱（A供B原料，B供C组件...）           │
│                                                          │
│  ③ 供需对接服务层                                         │
│     • "谁需要我" — 自动匹配下游需求方                     │
│     • "我需要谁" — 自动匹配上游供应商                     │
│     • 供需信息发布与撮合                                    │
│                                                          │
│  ④ 政府决策支持层                                         │
│     • 强链补链分析（缺哪一环、该招什么企业）                │
│     • 供应链风险预警（关键企业依赖度过高、断链风险）          │
│     • 产业招商地图（目标企业推荐、落地可行性评估）           │
│                                                          │
│  ⑤ 数据底座层                                             │
│     • 企业数据采集（工商、税务、招投标、专利、招聘等）        │
│     • 产业链知识图谱（节点建模、关系抽取、推理）             │
│     • 数据更新与维护机制                                    │
└─────────────────────────────────────────────────────────┘
```

---

## 五、一句话总结

> **区政府要的不是"画一张图"，而是要一个"能看清产业家底、能发现断链风险、能撮合供需对接、能指导招商引资"的产业治理智能中枢。**
