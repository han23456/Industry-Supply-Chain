### 1.3 功能详解

#### 1.3.1 三维产业治理筛选器

**字段表格：**

| 字段 | 类型 | 说明 | 校验规则 |
|---|---|---|---|
| filter_strategic | Enum[] | 战略导向筛选值 | 可多选，默认["all"] |
| filter_lifecycle | Enum[] | 生命周期筛选值 | 可多选，默认["all"] |
| filter_enabling | Enum[] | 交叉使能筛选值 | 可多选，默认["all"] |
| result_count | Int | 筛选结果数量 | 实时计算，只读 |

**枚举值表格：**

| 维度 | 值 | 说明 | 计数颜色 |
|---|---|---|---|
| 战略导向 | `all` | 全部 | 灰色 |
| 战略导向 | `chain_master` | 链主产业 | 深蓝 `#096DD9` |
| 战略导向 | `core_pillar` | 核心支柱 | 蓝色 `#1890FF` |
| 战略导向 | `cultivating` | 培育中 | 橙色 `#FA8C16` |
| 生命周期 | `all` | 全部 | 灰色 |
| 生命周期 | `future` | 未来产业 | 紫色 `#722ED1` |
| 生命周期 | `emerging` | 新兴产业 | 蓝色 `#1890FF` |
| 生命周期 | `advantage_traditional` | 优势传统 | 绿色 `#52C41A` |
| 交叉使能 | `all` | 全部 | 灰色 |
| 交叉使能 | `ai` | +AI | 靛蓝 `#2F54EB` |
| 交叉使能 | `iot` | +物联网 | 绿色 `#389E0D` |
| 交叉使能 | `green_energy` | +绿色能源 | 青色 `#13C2C2` |
| 交叉使能 | `industrial_internet` | +工业互联网 | 玫红 `#EB2F96` |

**筛选逻辑规则：**

| 规则 | 说明 |
|---|---|
| 维度间关系 | **"与"关系**：三个维度的选中条件同时满足才展示 |
| 维度内关系 | **"或"关系**：同一维度内多选时，满足任一条件即展示 |
| 默认状态 | 三个维度均选中`all`，展示全部产业 |
| 计数更新 | 括号内数字实时联动，反映当前其他维度条件下的可选数量 |
| 空结果处理 | 筛选结果为空时，展示"无符合条件的产业"提示，并提供"重置筛选"按钮 |

**交互说明：**
- 点击选项：切换选中/未选中状态，选中为蓝色实心圆+蓝色文字，未选中为灰色空心圆+灰色文字
- 点击`[重置筛选]`：恢复全部维度为`all`，卡片区恢复展示全部产业
- 筛选变更：卡片区实时更新（300ms过渡动画opacity），无页面刷新
- URL同步：筛选条件同步到URL Query参数，支持分享和浏览器前进/后退

#### 1.3.2 核心指标栏

**字段表格：**

| 指标卡 | 指标值 | 计算逻辑 | 颜色规则 | 趋势对比 |
|---|---|---|---|---|
| 战略产业总数 | Int | 当前筛选条件下的产业链数量 | 蓝色 `#1890FF` | — |
| 急需补链数 | Int | 有严重缺失环节（覆盖度<20%）的产业数 | 红色 `#F5222D`，≥1时带脉冲呼吸动画 | — |
| 平均完整度 | Float | 当前筛选产业完整度评分的算术平均 | 环形进度条，≥80%绿，60-80%蓝，<60%红 | 环比上月箭头+数值 |
| 数字化渗透率 | Float | 应用使能技术的企业数 / 总企业数 | 蓝色 `#1890FF` | 环比上月箭头+数值 |

**量化规则：**

| 指标 | 公式 | 阈值 |
|---|---|---|
| 急需补链判定 | `存在环节覆盖度<20%` | — |
| 平均完整度 | `Σ(score_i) / count` | 0-100 |
| 数字化渗透率 | `enabling_enterprise_count / total_enterprise_count` | 0-100% |
| 趋势对比 | `(本月值 - 上月值) / 上月值 * 100%` | 正数绿色↑，负数红色↓ |

**交互说明：**
- 指标卡hover：轻微上浮（translateY: -2px），阴影加深
- 点击"平均完整度"卡：下钻完整度趋势分析（弹窗或跳转）
- 点击"急需补链数"卡：自动筛选，卡片区按完整度升序排列，缺失产业置顶

**排序规则：**

| 优先级 | 排序维度 | 规则 | 说明 |
|---|---|---|---|

| 2 | 完整度 | 升序排列（低的在前） | 完整度越低越需要关注 |
| 3 | 企业规模 | 按营收降序 | 同完整度下，大产业优先 |
| 4 | 战略优先级 | 链主产业>核心支柱>培育中 | 同规模下，战略地位高的优先 |

## 四、交互流程

### 4.1 产业全景看板 → 产业链结构图谱

```
用户从产业全景看板点击某张产业卡片
    │
    ├── 路由跳转至 /industry/chain-graph/:chainId
    ├── 携带 chainId 参数
    └── 保留看板筛选条件（用于返回时恢复）
    │
    ▼
页面加载
    │
    ├── 查询产业链基础信息（顶部信息栏）
    ├── 查询产业链环节树（左侧导航树）
    ├── 查询企业环节关联（节点企业数）
    ├── 查询企业关系数据（连线数据：交易/股权/推断/使能）
    ├── 查询使能技术标签（节点标签）
    └── 默认渲染关系视图（企业供需网络图）
    │
    ▼
用户与图谱交互
    │
    ├── 切换视图标签 → 切换主可视化区内容
    ├── 点击左侧树节点 → 主区聚焦/高亮对应节点
    ├── 点击关系视图节点 → 滑出右侧抽屉（企业详情）
    ├── 拖拽画布 → 平移视角
    ├── 滚轮缩放 → 调整缩放比例
    └── 点击布局切换 → 切换层次/力导向布局
    │
    ▼
用户与抽屉交互
    │
    ├── 点击企业行 → 跳转企业画像详情页
    ├── 点击使能技术扇区 → 筛选企业列表
    ├── 点击"加入补链分析" → 跳转强链补链分析页
    └── 点击关闭/遮罩 → 收起抽屉
    │
    ▼
用户点击"返回看板"
    │
    └── 路由返回 /industry/panorama，恢复原筛选条件
```

### 4.2 页面流转关系

| 起点 | 操作 | 终点 | 携带参数 | 返回行为 |
|---|---|---|---|---|
| 产业全景看板 | 点击产业卡片 | 产业链结构图谱 | `chainId` | 点击"返回看板"恢复筛选条件 |
| 产业链结构图谱 | 点击企业行（抽屉内） | 企业画像详情 | `enterpriseId` | 浏览器返回 |
| 产业链结构图谱 | 双击关系视图节点 | 企业关系网络图 | `enterpriseId` | 浏览器返回 |
| 产业链结构图谱 | 点击"加入补链分析" | 强链补链分析 | `chainId`, `nodeId` | 浏览器返回 |
| 产业链结构图谱 | 点击缺口项（缺口视图） | 供需缺口分析 | `category` | 浏览器返回 |
| 产业链结构图谱 | 点击场景零部件（场景视图） | 供需缺口分析 | `component` | 浏览器返回 |

## 五、非功能需求

| 类别 | 需求 |
|---|---|
| 性能 | 关系视图渲染≤2s（50个节点以内），节点交互响应≤100ms，抽屉滑出动画300ms，视图切换动画300ms |
| 兼容性 | 支持Chrome 90+、Edge 90+、Firefox 88+，分辨率1920×1080 |
| 可访问性 | 支持键盘导航（Tab切换节点、Enter打开抽屉、ESC关闭抽屉/退出全屏） |

| 状态保持 | 缩放比例、布局类型、视图选择、节点位置（如手动拖拽）本地缓存（localStorage），刷新后恢复 |
| 数据更新 | 企业关系数据每日增量更新，环节树结构变更后实时刷新 |

### 6.1 术语表

| 术语 | 说明 |
|---|---|
| 战略导向 | 产业在区域战略中的定位：链主产业、核心支柱、培育中 |
| 生命周期 | 产业所处发展阶段：未来产业、新兴产业、优势传统 |
| 交叉使能 | 产业应用的横向使能技术：AI、物联网、绿色能源、工业互联网 |
| 存量指标 | 产业当前的经济贡献：税收、就业、营收 |
| 增量指标 | 产业的动态增长：在建项目、招商落地、增速 |
| 完整度评分 | 产业链各环节覆盖度的加权评分（0-100） |
| 环节覆盖度 | 实际企业数 / 参考基准企业数 |
| 叶子节点 | 产业分类树的最末端节点，可直接关联企业 |
| 已验证关系 | 有税务发票记录的企业间交易关系 |
| 推断关系 | 基于产品匹配但无交易记录的企业间潜在关系 |
| 层次布局 | 图谱布局算法：按产业环节分层排列 |
| 力导向布局 | 图谱布局算法：基于物理模拟的自动分布 |
| 本地闭环 | 供需双方均在本区，交易关系在本地完成 |
| 外流风险 | 本区企业依赖外地供应商，存在断链或成本风险 |
