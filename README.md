# 产业链/供应链图谱系统 — V2 前端原型

依据《产业链供应链系统_产业图谱完整PRD_V2.md》实现的高保真政务系统前端原型。

## 核心变更（V2）

- **产业全景看板**：新增左侧功能导航，聚焦产业矩阵视图
- **产业链结构图谱**：从单一结构视图升级为**四视图**
  - **结构视图**：产业 L1→L2→L3→L4 分类树横向展开
  - **关系视图（默认）**：企业供需关系网络图，支持 4 种关系类型、力导向/层次布局
  - **缺口视图**：缺失/薄弱环节列表，标注影响范围与招商建议
  - **场景视图**：应用场景 → 零部件需求拆解，标注本区有无
- **左侧产业分类树**：所有视图共享的纵向导航锚点
- **右侧抽屉**：点击节点/企业/缺口/零部件后滑出详情

## 技术栈

- 纯 HTML5 / CSS3 / JavaScript（原生实现，无 UI 框架依赖）
- ECharts 5.5.0（树图、网络图、热力图、饼图）
- 原生 DOM 操作 + Mock 数据

## 页面说明

| 页面 | 文件 | 路径 |
|---|---|---|
| 产业全景看板 | `index.html` | `/industry/panorama` |
| 产业链结构图谱 | `chain-graph.html` | `/industry/chain-graph/:chainId` |

## 快速启动

```bash
node server.js
```

访问：
- 看板：http://localhost:8080/index.html
- 机器人产业链图谱：http://localhost:8080/chain-graph.html?chainId=chain-robot

## 已实现功能

### 产业全景看板

- 三维产业治理筛选器（战略导向 × 生命周期 × 交叉使能）
- 4 项核心指标卡
- 产业矩阵卡片
- 底部快捷分析：供需缺口 TOP5、供应链风险 TOP5、支撑产业活跃度热力图

### 产业链结构图谱

- 顶部信息栏、完整度评分、操作按钮
- 左侧产业分类树：3-4 层、展开/收起、本区有/只看缺失筛选
- **结构视图**：ECharts 横向树形图
- **关系视图**：企业供需网络图，4 种连线（交易/股权/推断/使能），2 种布局
- **缺口视图**：缺失/薄弱环节卡片，含影响范围与招商建议
- **场景视图**：场景列表 + 零部件拆解清单
- 右侧滑出抽屉：企业/环节详情、使能技术饼图、企业列表
- 底部状态栏：图例筛选、布局切换、缩放控制
- 全屏模式（ESC 退出）、完整度评分明细弹窗、返回看板保留筛选条件

## 备注

本原型使用前端 Mock 数据模拟后端 API 响应，所有交互均可直接在浏览器中运行验证。
